## STEP-BY-STEP SETUP

### 1️⃣ **Create Project Structure**
Open terminal in `c:\wp\project\protechQ` and run:

```bash
mkdir -p src\components\pages
```

Or manually create these folders in VS Code:
- Right-click in Explorer
- New Folder
- Create: `src` → inside create `components` and `pages`

### 2️⃣ **Copy React Code**

**File: `src/main.jsx`**
```javascript
import React from 'react'
import ReactDOM from 'react-dom/client'
import App from './App.jsx'
import './index.css'

ReactDOM.createRoot(document.getElementById('root')).render(
  <React.StrictMode>
    <App />
  </React.StrictMode>,
)
```

**File: `src/App.jsx`**
- Copy from: `APP_JSX_CODE.txt`

**File: `src/App.css`**
- Copy from: `APP_CSS_CODE.txt`

**File: `src/index.css`**
```css
@import url('https://fonts.googleapis.com/css2?family=Orbitron:wght@400;600;700;900&family=Syne:wght@400;500;600;700&family=Space+Mono:wght@400;700&display=swap');
```

### 3️⃣ **Install Dependencies**

```bash
npm install
```

### 4️⃣ **Start Development Server**

```bash
npm run dev
```

Server starts at: `http://localhost:5173`

## 🆘 TROUBLESHOOTING

**Issue**: Module not found
**Solution**: Run `npm install` in the project folder

**Issue**: Styling not loading
**Solution**: Ensure `index.html` has `<div id="root"></div>`

**Issue**: Port 5173 already in use
**Solution**: Kill the process or use `npm run dev -- --port 3000`
